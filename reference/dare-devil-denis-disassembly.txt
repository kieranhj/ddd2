Dare Devil Denis disassembly
============================
Dare Devil Denis, also known as Daredevil Dennis, was written by Simon Pick,
and was published by Visions Software for the BBC Micro in 1984. It is a
platform game in which the player must jump over and avoid obstacles.

The following disassembly was created by reverse engineering binary images,
without access to any source code. It is nevertheless reasonably complete,
allowing the technical approaches used to be understood.

The author of this disassembly imposes no additional copyright restrictions
beyond those already present on the game itself. It is provided for educational
purposes only, and it is hoped that the original authors will accept it in the
good faith it was intended - as a tribute to their skills.

Technical notes
===============
The first BASIC loader uses embedded control characters to hide the actual code
run if listed, and instead displays alternative code intended to confuse
pirates.

Interesting pokes
=================
&1b51 = &60
infinite takes

&1550 = &4c, &1551 = &08, &1552 = 15
invulnerability
